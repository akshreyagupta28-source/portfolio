## About

This is my personal portfolio website — a cyberpunk-themed single-page site showcasing who I am, my technical skills, projects, internships, and education. It's built with plain HTML, CSS, and JavaScript, so it runs anywhere with no build step or dependencies.

## Features

- Animated cyberpunk grid background with glassmorphism cards
- Hero section with a clean, simple headline
- About Me section with profile picture
- Tech stack section with animated skill progress bars
- Projects section displaying my GitHub projects
- Experience timeline (Data Science internships)
- Education section

## Projects Shown

**Credit Card Fraud Detection**
Trained a classifier to flag fraudulent transactions. The tricky part was the class imbalance, since fraud cases are rare, so a chunk of this project was just about handling that properly.
Repo: https://github.com/akshreyagupta28-source/Credit-Card-Fraud-Detection

**Customer Churn Prediction**
Built a model to predict which telecom customers are likely to churn, working through data cleaning, feature engineering, and comparing a few classification algorithms.
Repo: https://github.com/akshreyagupta28-source/Customer_Churn_Prediction

**Blood Donation Management**
A mini project based on the concepts of Object-Oriented Programming (OOP) for managing blood donation records and operations.
Repo: https://github.com/akshreyagupta28-source/blood-donation-management

**Random Password Generator**
A small Python script that spits out secure, customizable passwords. Simple, but a good exercise in working with Python's string and random modules.
Repo: https://github.com/akshreyagupta28-source/Random_password

**Guess the Number Game**
One of my earliest Python projects, a console-based guessing game. Nothing fancy, just good practice with loops and conditionals.
Repo: https://github.com/akshreyagupta28-source/guess-the-number-
